# Changelog preview — custom range

Build a changelog between two git refs.

| Key | Action |
|-----|--------|
| **Tab** | Switch From / To |
| **1** / **2** | Focus From / To |
| **← / →** | Change selected ref |
| **Ctrl+S** | Save preview to `changelog_temp.md` |
| **Enter** / **F2** / **Esc** | Close |
