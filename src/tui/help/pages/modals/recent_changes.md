# Recent Changes

Full-screen git log for the selected project scope.

| Key | Action |
|-----|--------|
| **1** / **2** | Recent vs History tab |
| **[** / **]** | Change scope |
| **← / →** | Move along history |
| **↑ / ↓** | Scroll |
| **R** | Reload |
| **T** | Create tag from selection |
| **Ctrl+R** | Rename commit message |
| **Esc** | Close |
