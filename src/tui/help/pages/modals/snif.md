# SNIF — Search, Narrow, Inspect, Fix

Project-wide search and replace across filtered paths.

| Key | Action |
|-----|--------|
| **Tab** | Switch field (filters / pattern / replacement) |
| **F2** | Run search or replace |
| **m** | Toggle Search vs Replace mode |
| **e** | Case-sensitive search |
| **a** | Case-insensitive replacement |
| **Esc** | Close |
