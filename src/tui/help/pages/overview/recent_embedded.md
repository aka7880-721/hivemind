# Overview — Recent Changes tab

When the terminal is short, git history moves into this tab instead of living only on the tiles view.

## Navigation

| Key | Action |
|-----|--------|
| **↑ / ↓** | Scroll the log |
| **G** | Open the full-screen Recent Changes dialog (same data, more room) |

## Scope

Use **[** and **]** to change which repo scope the log shows, when multiple scopes exist.

## Tips

- On taller terminals this tab may be hidden; use **G** from the dashboard footer anytime.
