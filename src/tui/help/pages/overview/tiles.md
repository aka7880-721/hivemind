# Overview — scope tiles

Scope tiles summarize each git scope (branch / repo) for the selected project.

## Navigation

| Key | Action |
|-----|--------|
| **← / →** | Move focus between tiles |
| **↑ / ↓** | Scroll when tiles do not fit |
| **Tab** | Switch to Projects pane |
| **1–4** | Jump to Overview tabs (when Overview is focused) |

## Actions on a focused tile

| Key | Action |
|-----|--------|
| **L** | ReleaseNOW for this scope |
| **B** | Bump version workflow |
| **Mouse** | Click tiles and action rows |

## Tile info rows

Some tiles rotate **dev** and **release** version rows. Use the on-tile controls or mouse to cycle what is shown.

## Related shortcuts

| Key | Action |
|-----|--------|
| **G** | Full-screen Recent Changes popup |
| **C** | Changelog preview |
| **T** | Create tag |
| **R** | Reload git activity |
