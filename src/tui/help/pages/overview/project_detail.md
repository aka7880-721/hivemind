# Overview — Project Detail tab

Static summary of the selected project: paths, type, and quick action reminders.

## What you see

- Project name and configuration highlights
- **Available actions** list mirroring common dashboard shortcuts

## Shortcuts (dashboard)

| Key | Action |
|-----|--------|
| **E** | Edit project metadata |
| **L** | ReleaseNOW |
| **G** | Git log popup |
| **C** | Changelog preview |
| **B** | Bump |
| **T** | Tag |
| **F** | SNIF search |

Switch to **Project Settings** tab (digit **4** or click) for editable fields.
