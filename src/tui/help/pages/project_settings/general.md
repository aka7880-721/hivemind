# Project Settings — General

Edit persisted project configuration. Changes save when you leave a field or use browse/save flows.

## Sub-tabs

| Key | Action |
|-----|--------|
| **[** / **]** | Previous / next settings sub-tab |
| **Tab** | Move between fields |
| **Space** | Toggle checkboxes (Changelogs tab) |

## Text fields

| Key | Action |
|-----|--------|
| **Ctrl+O** | Open file browser for path fields |
| **PgUp / PgDn** | Scroll long forms |

## Sub-tab overview

- **General** — name, roots, project type, integration mode
- **Changelogs** — paths, templates, Top Picks, std changelog options
- **Distro** — distribution / packaging targets
- **ReleaseNOW & QD** — release automation and quick-download mirrors (when ReleaseNOW is enabled)
