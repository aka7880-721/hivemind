# Project Settings — ReleaseNOW & QD

Release automation and Quick Download mirror settings. This tab appears when ReleaseNOW is enabled for the project.

## Highlights

- ReleaseNOW run options and defaults
- README injection depth and templates
- Quick Download artifact mirrors

## Navigation

| Key | Action |
|-----|--------|
| **Tab** | Move between fields |
| **[** / **]** | Switch sub-tabs |
| **Ctrl+O** | Browse paths |

Use **L** from the dashboard Overview to start a ReleaseNOW run for a scope.
