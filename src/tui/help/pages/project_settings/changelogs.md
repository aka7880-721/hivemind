# Project Settings — Changelogs

Configure how ComfyGit generates and stores changelogs.

## Common actions

| Key | Action |
|-----|--------|
| **Space** | Toggle changelog-related checkboxes |
| **[** / **]** | Switch sub-tabs |
| **Ctrl+O** | Browse for changelog paths |
| **P** | Open Top Picks editor (when available) |

## Fields

- Changelog file paths and templates
- Standard changelog options and mirroring
- Top Picks curation for release notes

Changes persist when you move between fields or save the project configuration.
