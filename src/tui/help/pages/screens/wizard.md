# New Project Wizard

Full-screen flow to add a project to ComfyGit.

## Navigation

| Key | Action |
|-----|--------|
| **Tab** | Next field |
| **Shift+Tab** | Previous field |
| **↑ / ↓** or **PgUp / PgDn** | Scroll the form |
| **Left / Right** | Change enum-style fields |

## Actions

| Key | Action |
|-----|--------|
| **F2** | Save project |
| **F5** | Read target version from disk |
| **Ctrl+O** | Browse for paths |
| **S** | Open UI Settings |
| **Esc** | Cancel wizard |
| **2** | Dashboard (after save or cancel) |

## Note

**?** help is disabled while a text field is active so typing `?` does not open this overlay.
