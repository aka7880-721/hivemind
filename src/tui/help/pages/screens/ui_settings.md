# UI Settings

Configure ComfyGit TUI presentation (footer, tab hints, etc.).

## Shortcuts

| Key | Action |
|-----|--------|
| **T** | Toggle tab hint visibility |
| **C** | Cycle footer content alignment |
| **H** | Hide footer globally |
| **N** | Jump to New Project wizard |
| **S** | Return to Dashboard |
| **1** | Dashboard |
| **Q** | Quit |
