# UI Settings

Configure ComfyGit presentation: footer, tab hints, and tab selection flash.

Open from any screen with **S** (same as screen **3**).

## Layout

Matches **Project Settings**: horizontal tab strip (**General**, **Tabs**) and a scrollable settings panel below.

## Shortcuts

| Key | Action |
|-----|--------|
| **[** / **]** | Previous / next settings tab |
| **↑** / **↓** or **Tab** | Move focus between fields |
| **Space** / **Enter** | Toggle checkbox or cycle value |
| **←** / **→** | Cycle footer alignment or flash color |
| **D** or **Esc** | Return to Dashboard |
| **1** | Dashboard |
| **N** | New Project wizard |
| **?** | Help |

## Tabs

### General

- **Show tab hints** — footer shortcut labels for tabs
- **Hide footer** — hide the bottom shortcut bar
- **Footer content** — centered vs left-aligned footer text

### Tabs

- **Tab selection flash** — border pulses twice when a tab is selected (overview, project settings, and this screen)
- **Flash color** — indexed ANSI color (default **46** green)

Settings are saved to your ComfyGit config file.
