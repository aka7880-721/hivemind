# Projects pane

The left column lists every project in your ComfyGit config.

## Navigation

| Key | Action |
|-----|--------|
| **↑ / ↓** | Move selection |
| **Tab** | Switch to Overview pane |
| **Mouse** | Click a project to select |

## Actions

| Key | Action |
|-----|--------|
| **N** | Create a new project (wizard) |
| **E** | Edit the selected project |
| **D** | Delete the selected project |
| **Enter** | Open the selected project in Overview |

## Tips

- The highlighted project drives everything in the Overview pane on the right.
- Press **1** to return to the Dashboard from Wizard or UI Settings.
